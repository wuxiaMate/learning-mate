폰 실기기 테스트 체크리스트

카메라 기능은 모바일부터 검증 (기획서 1장). 앱 대신 폰 브라우저로 같은 주소를 열어요.
개발 서버를 폰에서 여는 방법
1PC와 폰을 같은 Wi-Fi에 연결하고 Vite를 --host 로 실행
2카메라는 HTTPS에서만 동작 → 개발용 인증서(basic-ssl) 또는 터널(ngrok·cloudflared)로 https 주소 만들기
3폰 브라우저에서 https 주소 접속 → 테스트 계정 로그인
4데모는 같은 HTTPS 배포 주소에서 PC + 폰 두 계정으로 시연
카메라 권한허용 · 거부 · 나중에 재허용 흐름 (거부 시 수동 모드)
iOS Safari 영상video에 playsinline · muted 지정, 전면 카메라 선택
화면 꺼짐Screen Wake Lock API로 집중 중 화면 유지 (미지원 시 안내)
백그라운드 탭타이머는 setInterval 누적 대신 시작 시각 기준 계산
배경음 자동재생사용자 탭 이후에만 재생, 음원 전환 시 이전 정지
탭 이탈 감지visibilitychange · 앱 전환/잠금 화면도 이탈로 처리
네트워크LTE/Wi-Fi 전환 시 WebSocket 재연결 · 오프라인 표시
저조도 · 가림판정 불가 → 수동 전환 안내, 오탐/누락 횟수 기록
