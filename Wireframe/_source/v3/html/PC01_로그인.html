1

소셜 로그인 (OAuth 2.0)공통

유일한 로그인 방법. Google·카카오·네이버 버튼 → 제공자 동의 화면 → /auth/callback/:provider → Spring이 인가 코드를 교환하고 사용자를 식별해 서비스 토큰 발급. 처음이면 자동 가입, 마지막에 쓴 제공자에 「최근 사용」 표시. 실제 버튼은 각 제공자 공식 리소스 사용.

2

Instagram — 검토 필요공통

Instagram 로그인은 비즈니스·크리에이터 계정에만 제공돼 일반 개인 계정은 쓸 수 없어요. 채택 여부·대안을 팀이 결정 (기획서 5장 팀 결정 항목).

3

소셜 로그인 전용공통

서비스 자체 로그인·회원가입·비밀번호 찾기는 두지 않아요. 처음 로그인하면 무호(닉네임)만 정하고 시작. 비밀번호를 저장하지 않음.

4

동의 · HTTPS공통M05

계속하면 약관 동의. 제공자별 리디렉션 URI는 HTTPS 주소로 등록하고, 카메라(getUserMedia)도 HTTPS에서만 동작해요.

5

진행 중 세션 안내M01

종료되지 않은 세션이 있으면 로그인 직후 폐관 수련 화면으로 복구해요.
